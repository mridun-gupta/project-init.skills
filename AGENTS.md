# AGENTS.md — project-init.skills repo

Public source repo for the `project-init` agent skill. Work here if you're improving the skill or its packaging — **not** a project generated by the skill.

## Repo map

- `skills/project-init/` — the skill (SKILL.md, templates/, references/, agents/, LICENSE)
- `.claude-plugin/` — Claude Code plugin + marketplace manifests
- `gemini-extension.json` — Gemini CLI extension manifest
- `scripts/` — install.ps1 / install.sh
- `.github/workflows/validate.yml` — CI frontmatter check

## Conventions

- Universal spec only in `SKILL.md` frontmatter: `name`, `description`, `argument-hint`, `license`.
- `{{TOKEN}}` placeholders in `templates/` must be defined in `SKILL.md` Step 2.
- Version bump = edit `CHANGELOG.md`, `.claude-plugin/plugin.json`, `.claude-plugin/marketplace.json`, `gemini-extension.json` together, then `git tag vX.Y.Z`.
- Repo URLs assume `github.com/mridun-gupta/project-init.skills` — update all docs if the repo is renamed.

## Verify

`python -c "import yaml,pathlib; ..."` or just run the workflow logic locally; then install to `~/.agents/skills/` and invoke `/project-init` on a scratch dir.
